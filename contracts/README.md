# contracts

監視側（`monitor/`）と UI 側（`ui/*`）の唯一の接点です。両者は互いのコードを参照せず、ここにある定義だけを共有します。

| パス | 内容 | 使う側 |
|---|---|---|
| `schema/001_init.sql` | テーブル、CHECK 制約、公開 VIEW の DDL | 監視側が埋め込んで適用する。UI のテストが一時 DB を作るのにも使う |
| `schema/columns.json` | 公開 VIEW の列定義の正本 | 両側のテスト |
| `schema/CONTRACT.md` | 各列の意味、列挙値、バージョンの規則 | 人間 |
| `models.json` | 組み込みのモデル表（コンテキストウィンドウ） | 監視側 |
| `fixtures/` | テスト用の入力データ。手で書く唯一の正で、自動生成しない | 両側のテスト |

ここにあるファイルの改行コードは LF に固定しています（`.gitattributes`）。
