# cc-ran 02 — UI（Avalonia）実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans。各ステップに担当（**[Claude]** / **[User]**）を付けてある。**[User]** のステップでは必ず止まり、完了の連絡を受けてから再開する。**[Claude] は `ui/avalonia/src/` のロジックと View を書かない**（スケルトンまで）。ユーザーが GREEN を頼んだ場合だけ例外。

**Goal:** `cc-ran-ui` を実装し、トレイのバッジと一覧ウィンドウで、どのセッションを確認しに行くべきかが一目で分かるようにする。

**Architecture:**
- `CcRan.Ui.Core`（Avalonia に依存しない）が DB の読み取り、ポーリング、ViewModel を持つ。`CcRan.Ui` は View、トレイ、アプリのライフサイクルだけを持つ。
- UI は判定ロジックを持たない。並び順と段階は `v_sessions` の値をそのまま使う。
- monitor のコードにも Zig にも依存しない。テストは `contracts/` から一時的な DB を作る。**plan 01 が終わっていなくても進められる。**

**Tech Stack:** .NET 10、Avalonia 12.1.5、Microsoft.Data.Sqlite 10.0.14、xUnit v3 3.2.2、Avalonia.Headless.XUnit、CommunityToolkit.Mvvm、Microsoft.Extensions.TimeProvider.Testing

**Spec:** `docs/specs/2026-11-05-cc-ran-design.md`（§7、§8.3、§10）、契約：`contracts/schema/CONTRACT.md`

## Global Constraints

- DB は **`Mode=ReadOnly;Pooling=False`** で開く。**UI は DB を作らない、書かない。** 読むのは `v_sessions` と `v_monitor` だけで、列名を指定する（`SELECT *` は使わない）。
- 長いトランザクションを張らない。読み終えたら接続を閉じるか、次のポーリングまで読み取りを残さない。
- 対応する契約の major は `1`。major が違えば、一覧を出さず「バージョン不一致」を表示する。
- データディレクトリの決定：`CC_RAN_HOME` > Windows `%LOCALAPPDATA%\cc-ran` > macOS `~/Library/Application Support/cc-ran`。
- ポーリングは 1 秒間隔で `PRAGMA data_version` を読む（spec §9）。時間は `TimeProvider` を注入して、テストで差し替える。
- トレイの件数は `needs_permission`、`needs_input`、`error`、`done` の合計（spec §7.1）。色は最も重い状態に合わせる。
- 認識できない `attention` などの列挙値が来てもクラッシュしない（契約の minor の範囲で増えることはないが、防御する）。
- Native AOT で動くように、リフレクションに頼らない（コンパイル済みバインディング、CommunityToolkit.Mvvm のソース生成）。`TreatWarningsAsErrors` のまま通す。
- `CcRan.Ui.Core` から Avalonia を参照しない。

## Review Focus

spec が前提にしているのに、見落としやすい条件。それぞれのテストは担当のタスクに入れてある。

1. **DB がない状態で起動する**：クラッシュせず、空の一覧と「監視停止中」を出す。DB を作らない。後から DB ができたら読み始める。（Task 2、3）
2. **実行中に DB が消える、壊れる、ロックされる**：ユーザーがデータディレクトリを削除した場合など。クラッシュせず、次のポーリングで回復する。（Task 3）
3. **経過時間の表示**：時計が戻って `attention_since` が未来になっても、負の時間を表示しない。（Task 4）
4. **長い名前と非 ASCII**：日本語の `display_name` と長い `cwd` で、一覧のレイアウトが崩れない。（Task 6）
5. **daemon の起動の失敗**：`cc-ran` が PATH にない場合、ボタンを押してもクラッシュせず、理由を表示する。（Task 5）
